# Changelog

## 0.1.0 — 2026-09-09

Initial single-worker implementation. Portable/Codex and Claude Code plugin
manifests, native marketplace entries, self-contained skill, Bash sequencing loop,
fresh Sol workers, bounded task packets and handoff, structured result validation,
optional independent host verification, durable Markdown checkpoints, worktree
locking, stop/resume, time/batch/stall/token boundaries and offline process tests.

Shared-worktree parallelism is researched but not implemented. Live model and
native-host qualification are explicitly separate from the offline test suite.
